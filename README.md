# Хроники Глубин

Браузерная MMORPG в духе классических корейских MMO начала 2000-х: четыре города, шесть зон охоты, катакомбы с боссом, прокачка до 40 уровня, инвентарь с куклой персонажа и комплектами брони, заточка, PvP с кармой, чат и мультиплеер. Работает прямо в браузере, на ПК и на телефоне.

Живой сервер: https://realms.neuraldeep.ru

Механика, названия и ассеты — свои. Текстуры и концепты моделей сгенерированы (OpenRouter), 3D-модели — TRELLIS.2.

## Стек

- Клиент: [three.js](https://threejs.org) r170 + Vite, без фреймворков.
- Сервер: Node.js 22, [ws](https://github.com/websockets/ws), SQLite (`node:sqlite`), пароли — scrypt.
- Тесты: `node:test` (правила, сервер) и Playwright (E2E в Chrome, включая мобильную раскладку и двух игроков).

## Запуск

```bash
npm install
npm run dev        # WS-сервер :8790 + Vite http://localhost:5173
npm test           # юнит → сервер → сборка → E2E
```

`?ws=ws://host:port` — свой адрес игрового сервера, `?touch` — мобильный интерфейс на ПК.

## Структура

| Путь | Что там |
| --- | --- |
| `src/data.js` | классы, умения, предметы, комплекты, мобы, магазин |
| `src/stats.js` | расчёт характеристик, экипировка, заточка (без DOM) |
| `src/pvp.js` | правила PvP: флаг, карма, отмыв, стражи |
| `src/world.js` | рельеф, зоны, города, катакомбы, спавны |
| `src/models.js`, `src/tex.js` | модели и текстуры |
| `src/main.js` | рендер, ввод, бой, интерфейс, сеть, чат |
| `server/` | игровой сервер и аккаунты |
| `tools/` | генерация текстур и концептов моделей (нужен `OPENROUTER_API_KEY` в `.env`) |
| `deploy/` | nginx, systemd, скрипт выкладки (`DEPLOY_HOST=user@host bash deploy/deploy.sh`) |

## Управление

ЛКМ — идти / цель / атака, ПКМ или два пальца — камера, колесо или щипок — зум, 1–5 и Shift+1–5 — умения, 6–7 — зелья, Tab — цель, F — атака, I — инвентарь, C — персонаж, M — карта, P — группа, V — сброс камеры, Enter — чат (`+текст` — торговля, `/w Имя текст` — личное, `/r` — ответ).
