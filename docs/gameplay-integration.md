# Игровое расширение на серверной архитектуре

Ветка основана на `9b5ee8a` основного репозитория. Прогресс, бой, мобы, питомцы, группы и выдача предметов рассчитываются сервером. Старый клиентский контроллер боя не переносится.

## Части для проверки

1. Камера и миникарта: [описание](camera-minimap.md).
2. Баланс PvE и стоимость перемещений: [описание](pve-travel.md).
3. Мир и визуальные материалы: общий для сервера и клиента мир с четырьмя городами, шестью зонами, лагерем орков, 384 исходными точками появления. Отдельные модели видов мобов, элиты и чемпионы, текстуры окружения, 12 PNG ресурсов. Существующие иконки экипировки и загрузчик мага автора сохранены.
4. Персонаж: GLB воина с десятью клипами, шаг по фактической скорости, атаки, боевой клич, смерть и празднование уровня вне боя. Кнопка обычной атаки, страницы умений на телефоне, выбор профессии и обучение у наставника.
5. Серверные механики: восемь профессий, SP и уровни умений; заряды и стрелы; эффекты, особые умения мобов и фазы боссов; питомцы; группы до семи игроков; предметы на земле с проверкой владельца, расстояния и однократной выдачи.

Основные новые модули: `server/sim/{groups,companions,ground-loot,mob-abilities}.js`. Геометрия не импортируется сервером: `world-core.js` и `camp-core.js` содержат данные, `world.js` и `camp-render.js` отвечают за Three.js.

## Проверка

```sh
npm ci
npm run test:unit
npm run test:server
npm run build
npm run test:e2e
```

Браузерные проверки включают создание и вход, бой и смерть, предметы, торговлю, телепорты, мобильную раскладку, двух игроков, PvP и камеру. Отдельный сценарий `tests/content.e2e.mjs` проверяет загрузку десяти клипов воина, анимацию клича, выбор двух профессий, обучение, призыв волка и создание группы через сервер. Также проверяются независимые скелеты двух сетевых воинов, единственная загрузка модели, клич, движение, атака, смерть, возрождение и выход игрока глазами наблюдателя.

Для ручной проверки создать человека-воина, проверить движение, атаку и боевой клич; посетить наставника после достижения нужного уровня; найти новую зону через хранителя врат. В группе проверить получение предмета только участником рядом и разделение опыта. Проверить босса, питомца и несколько профессий на продолжительной игровой сессии: автоматические проверки не заменяют балансировку всех сочетаний экипировки.

## Ассеты и границы реализации

- `public/assets/warrior/meshy/guardian-game.glb` — около 8,52 MB, подготовлен из предоставленного владельцем работы архива Meshy. Это не CC0-ассет; его происхождение не меняет условия сервиса, на котором он получен.
- Доспех в этой модели цельный. Его внешний вид пока не заменяется по слотам экипировки; характеристики экипировки применяются. Модель используется у локального и сетевых людей-воинов. У каждого экземпляра независимый скелет и проигрыватель анимаций; файл, геометрия и текстуры переиспользуются. Другие классы сохраняют свои модели. Это ограничение явно отделено от работающих анимаций.
- Новые PNG ресурсов находятся в `public/assets/icons/resources`; файлы генерации перечислены рядом. Новая генерация иконок одежды и оружия не входит в изменение: используются существующие иконки автора.
- DoT и ослабляющие умения сейчас применяются к мобам; распространение этих эффектов на PvP требует отдельной настройки правил. Прямой PvP-урон, флаги и карма сохранены.
- Материалы подбираются автоматически вблизи, снаряжение — нажатием на предмет. Деньги выдаются сразу. Предметы исчезают через 30 секунд.
- Нет новой системы крафта и законченного комплекта сменной брони для всех рас.

## Сохранения и запуск

Сохранён формат профиля автора v3 с добавлением полей профессии, SP, выученных умений и зарядов через миграцию. Профили старого клиентского прототипа v2 авторский сервер пересоздаёт; перед переходом с прототипа нужна резервная копия и отдельный перенос аккаунтов. Не следует запускать тестовую ветку на единственном экземпляре старой базы.

Проверки работают с временными базами. Изменение не выкладывает приложение на живой сервер и не меняет его данные.
