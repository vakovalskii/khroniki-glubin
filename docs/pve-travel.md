# Баланс PvE, возврат мобов и телепорты

База: `9b5ee8a` (`main`). Изменения применены в серверной симуляции; клиент не задаёт урон, здоровье или стоимость.

## Правила

- Обычный моб преследует до 180 м от места появления вместо 60 м, босс — до 140 м. Расстояние более 220 м до цели также прекращает погоню.
- Возврат к месту появления не лечит моба. Восстановление начинается через 5 секунд после выхода из погони/возврата, только в спокойном состоянии и не дальше 8 м от дома: 2% максимального HP в секунду. Повторный бой прерывает восстановление. Настоящее возрождение после смерти по-прежнему восстанавливает полное здоровье.
- Исходящий урон игрока по мобам умножается на 0,65. За каждый уровень моба сверх разницы +2 действует дополнительный множитель 0,88, ограниченный снизу 0,25. При исходном уроне 100: равный уровень — 65, +4 — 50, +6 — 39. PvP и входящий урон мобов не изменены.
- Платные телепорты дешевле в четыре раза: луга 20, лес 50, пустошь 100, катакомбы 150 монет. Городские остаются бесплатными. Источник цен общий: `src/world-core.js`.

## Проверка

`npm run test:unit`, `npm run test:server`, `npm run build`, `npm run test:e2e`.

Регрессии проверяют продолжение погони на 100 м, возврат после 180 м, отсутствие лечения в пути, паузу и скорость восстановления, штраф урона по уровню, общий список цен. Сквозная проверка телепорта ожидает фактическое списание 20 монет сервером. Серверный прогон сохраняет проверки защиты от поддельного урона, прогресса, перемещения и PvP.

Это начальная настройка PvE, проверенная функционально, а не измеренный баланс всех сочетаний уровня и экипировки. Новые классы, питомцы и наземная добыча входят в отдельный большой пакет и здесь не добавляются.

Для E2E доступны `E2E_PORT`, `E2E_WS`, `PW_CHANNEL`, `E2E_RENDERER`; по умолчанию используется установленный Playwright Chromium и Metal на macOS.
