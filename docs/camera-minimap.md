# Камера и миникарта

База: `9b5ee8a` (`main`, серверная симуляция). Эта часть не меняет протокол, бой или сохранения.

## Поведение

- При перетаскивании ПКМ вправо yaw увеличивается, вниз pitch уменьшается. Знаки касаний и орбиты трекпада согласованы с мышью; зум прежний.
- Миникарта вращается вместе с камерой: движение вперёд на экране соответствует движению вверх на миникарте, вправо — вправо. Поворот применяется и к объектам, и к стрелке героя.
- Большая карта остаётся ориентированной на север. В катакомбах большая карта сохраняет обзор всего подземелья, миникарта показывает окрестности и выход в системе камеры.
- `src/map-view.js` содержит чистое преобразование координат; у него нет зависимости от DOM и three.js.

## Проверка

`npm run test:unit`, `npm run build`, `npm run test:e2e`.

Модульная проверка покрывает четыре поворота камеры и неподвижную большую карту. Браузерный сценарий проверяет реальное перетаскивание ПКМ по двум осям.

E2E использует установленный Playwright Chromium; `PW_CHANNEL=chrome` позволяет выбрать системный Chrome. На macOS выбран Metal, на других ОС SwiftShader; `E2E_RENDERER` переопределяет выбор. `E2E_PORT` и `E2E_WS` позволяют не занимать порты открытой игры. При первом запуске нужен `npx playwright install chromium`.
